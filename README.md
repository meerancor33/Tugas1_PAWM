# Tugas1_PAWM
II3140 Web and Mobile Application Development

Virtual Lab Kimia adalah platform pembelajaran interaktif berbasis web yang dirancang untuk membantu mahasiswa TPB ITB mempelajari konsep-konsep kimia melalui modul pembelajaran yang di dalamnya terdapat file Power Point, video YouTube, serta simulasi virtual. Website ini memungkinkan mahasiswa untuk mempelajari konsep-konsep kimia secara menyenangkan melalui flashcard, kuis, serta games interaktif serta mengakses materi tersebut dengan mudah dan aman tanpa batasan ruang dan waktu.
