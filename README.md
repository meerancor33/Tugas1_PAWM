# Tugas1_PAWM
**II3140 Web and Mobile Application Development**

## 📘 Deskripsi Proyek
**Virtual Lab Kimia** adalah platform pembelajaran interaktif berbasis web yang dirancang untuk membantu mahasiswa **TPB ITB** dalam mempelajari konsep-konsep kimia secara lebih efektif dan menarik. Platform ini menyediakan berbagai modul pembelajaran yang dilengkapi dengan:

- **Materi dalam bentuk PowerPoint (PDF)**
- **Video pembelajaran YouTube**
- **Simulasi virtual**
- **Flashcard interaktif**
- **Kuis dan games edukatif**

Website ini memungkinkan mahasiswa untuk belajar kapan saja dan di mana saja tanpa batasan ruang dan waktu, dengan antarmuka yang sederhana, mudah digunakan, serta aman.
